# Code of Conduct

## Short version

Be kind, be direct, assume good intent. We're all here because old code
deserves a second chance.

## Longer version

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. In short:

- Harassment, insults, and personal attacks are out.
- Technical disagreement is welcome — keep it about the code.
- Maintainers may remove comments or contributions that violate this.

If something feels off, reach out to the maintainers privately and we'll
handle it.
